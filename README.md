# 🖼️ AI Image Caption Generator

A simple Python project for generating image captions using Hugging Face's BLIP (Bootstrapped Language-Image Pretraining) models.

## 📦 Requirements

- Python 3.x
- transformers
- pillow
- requests

Install them via:
(bash)
pip install -r requirements.txt

🚀 How to Use

Open the notebook image_caption_generator.ipynb on Google Colab.

Run all cells.

Replace the image URL with your own, or upload an image locally (optionally).

Get the AI-generated caption for your image! 📸✨
